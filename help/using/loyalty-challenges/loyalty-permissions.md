# 충성도 과제 권한 {#loyalty-permissions}

## 개요 {#overview}

[!DNL Adobe Journey Optimizer] 충성도는 Adobe Admin Console RBAC(역할 기반 액세스 제어)를 사용하여 사용자 액세스를 관리합니다.

사용자가 충성도 작업을 수행하려면 먼저 역할을 할당해야 합니다. 할당된 역할이 없는 사용자는 충성도 서비스 엔드포인트에 대한 액세스가 거부됩니다. 사용자를 충성도에 온보딩하기 전에 서비스를 사용할 각 사용자에게 적절한 역할을 할당하십시오.

역할은 개별 사용자에게 직접 할당하거나 사용자 그룹을 통해 할당할 수 있습니다. [사용자에게 역할을 할당하는 방법을 알아보세요](#assign-roles).

## 권장 역할 {#recommended-roles}

로열티는 **Prod** 샌드박스에 대해 사전 구성된 세 가지 기본 역할을 제공합니다. 신규 고객은 이러한 역할을 있는 그대로 사용할 수 있습니다.

### 충성도 관리자 {#loyalty-administrator}

**충성도 관리자** 역할은 문제, 구성, 제품 카탈로그 및 통찰력과 같은 모든 충성도 기능에 대한 완전한 관리 액세스를 제공합니다.

| 사용 권한 | 설명 |
| - | - |
| 충성도 문제 관리 | 과제 생성, 편집, 삭제, 게시, 게시 취소 및 아카이빙, 여정 생성 트리거 |
| 충성도 기본 구성 관리 | 기본 조직 구성 만들기, 편집 및 삭제 |
| 충성도 고급 구성 관리 | 중요한 자격 증명 값에 대한 읽기/쓰기 액세스를 포함하여 보상 끝점 및 이벤트 변환 설정 관리 |
| 충성도 제품 카탈로그 관리 | 제품 카탈로그 항목 보기, 가져오기 및 편집 |
| 충성도 통찰력 관리 | 인사이트 보기, KPI 구성 업데이트 및 인사이트 파이프라인 트리거 |

### 충성도 전문가 {#loyalty-practitioner}

**충성도 전문가** 역할은 전체 과제 라이프사이클을 관리하고 기본 구성을 편집하는 비즈니스 소유자를 위해 설계되었습니다. 보상 구성, 이벤트 구성 및 제품 카탈로그 액세스는 읽기 전용입니다. 삭제 및 고급 구성 쓰기는 허용되지 않습니다.

| 사용 권한 | 설명 |
| - | - |
| 충성도 문제 관리 | 과제 생성, 편집, 삭제, 게시, 게시 취소 및 아카이빙, 여정 생성 트리거 |
| 충성도 기본 구성 | 기본 조직 구성을 만들고 편집합니다. 삭제가 허용되지 않음 |
| 충성도 보상 구성 보기 | 공급자, 정의 및 프록시를 포함한 보상 구성을 봅니다. 중요한 값은 제외됩니다. |
| 충성도 이벤트 구성 보기 | 이벤트 정의 및 이벤트 변환 매핑 보기 |
| 충성도 제품 카탈로그 보기 | 제품 카탈로그 항목 보기 및 가져오기 작업 상태 |
| 충성도 통찰력 개발 | 인사이트 데이터 보기 및 insight 카드 업데이트 |

### 충성도 분석가 {#loyalty-analyst}

**충성도 분석가** 역할은 과제, 제품 카탈로그 및 인사이트에 대한 읽기 전용 액세스를 제공합니다. 보고 및 감사 목적으로 이 역할을 사용하십시오.

| 사용 권한 | 설명 |
| - | - |
| 충성도 문제 보기 | 문제 보기 |
| 충성도 제품 카탈로그 보기 | 제품 카탈로그 항목 보기 및 가져오기 작업 상태 |
| 충성도 인사이트 보기 | AI가 생성한 insight 카드, 상태 바이탈 및 챌린지 성능 데이터 보기 |

## 기본 역할 범위 {#default-role-scope}

>[!IMPORTANT]
>
>기본 충성도 역할은 **Prod** 샌드박스로만 범위가 지정됩니다.

스테이징 또는 개발 샌드박스와 같은 비프로덕션 샌드박스에 대한 액세스 권한을 사용자에게 부여하려면 해당 샌드박스에 대한 사용자 정의 역할을 생성하고 해당 기본 역할과 동일한 권한을 할당합니다.

## 사용자에게 역할 할당 {#assign-roles}

>[!IMPORTANT]
>
>제품 관리자와 시스템 관리자만 사용자, 그룹 및 역할을 관리할 수 있습니다.

Adobe Admin Console에서는 역할을 사용자와 연결하는 두 가지 접근 방식을 지원합니다.

### 사용자를 역할에 직접 할당 {#assign-users-directly}

개별 사용자를 역할에 직접 추가합니다. 이 접근 방식은 소규모 팀이나 일회성 과제에 가장 적합합니다.

### 사용자 그룹 사용 {#use-user-groups}

사용자 그룹을 만든 다음 그룹에 사용자와 역할을 모두 할당합니다. 이 접근 방식은 부서 또는 기능별로 대규모로 액세스를 관리하는 데 가장 적합합니다.

역할, 그룹 및 사용자 관리에 대한 단계별 지침은 Adobe Journey Optimizer 액세스 제어 설명서를 참조하십시오.

* [사용자 및 역할 관리](../administration/permissions.md)
* [기본 제공 권한](../administration/ootb-permissions.md)

## 액세스 문제 해결 {#troubleshooting}

사용자가 충성도 과제 또는 관련 기능에 액세스할 수 없는 경우 다음을 확인하십시오.

* 사용자가 충성도 역할에 할당됩니다.
* 역할에는 충성도 문제가 활성화된 샌드박스가 포함됩니다.
* 역할에는 사용자가 수행하려는 작업에 필요한 권한이 포함됩니다.
* 비프로덕션 샌드박스의 경우 해당 샌드박스에 대해 사용자 정의 역할이 생성되었습니다.
* 조직 및 샌드박스는 충성도 문제에 대해 활성화됩니다.

권한이 업데이트된 후에도 액세스 문제가 지속되면 Adobe 담당자에게 문의하십시오.
