# 콘텐츠 카드 시작 {#get-started-content-card}

>[!BEGINSHADEBOX]

**이 페이지의 내용:** 콘텐츠 카드는 모바일 앱과 웹 사이트 내에서 사용자에게 맞춤형 메시지를 방해 없이 전달하여, 사용자가 하던 작업을 중단하지 않고도 상황에 맞는 참여를 유도합니다.

>[!ENDSHADEBOX]

콘텐츠 카드는 모바일 앱 및 웹 사이트에서 직접 개인화되고 흥미로운 콘텐츠를 제공하는 Adobe Journey Optimizer의 새로운 디지털 메시징 기능입니다. 기존 푸시 알림과 달리 콘텐츠 카드는 사용자 인터페이스에 원활하게 통합되어 사용자 상호 작용과 경험을 향상시키고 방해하지 않는 지속적인 업데이트를 제공합니다.

이 기능을 통해 마케터는 사용자에게 관련성이 높은 리치 미디어 콘텐츠를 제공할 수 있으므로 참여도가 높아지고 사용자 여정을 중단하지 않고도 중요한 메시지를 볼 수 있습니다.

## 사용 사례

콘텐츠 카드는 메시지가 도착하는 즉시 중단하지 않고 사용자가 원하는 속도로 작업을 수행할 수 있도록 메시지를 유지하려는 경우 가장 잘 작동합니다.

| 이점 | 이유 | 예시 사용 사례 |
| --- | --- | --- |
| 지속적인 가시성 | 카드는 사용자가 폐기할 때까지 앱 또는 웹 사이트에 남아 있습니다 | 진행 중인 프로모션, 사용자가 다시 방문할 수 있는 기능 강조 |
| 비간섭 게재 | 사용자를 중단하지 않고 인터페이스에 통합됩니다. | 다른 콘텐츠와 함께 표시되는 수동 업데이트 |
| 푸시 옵트인 없이 작동 | 푸시 알림 동의에 관계없이 인앱 또는 현장 게재됨 | 푸시 알림을 비활성화한 사용자에게 연결 |
| 시각적으로 풍부한 메시징 | 미디어 및 call-to-action 버튼 지원 | 이미지와 &quot;지금 구매&quot; 버튼이 있는 제품 스포트라이트 |

## 사용하지 않을 때

콘텐츠 카드는 사용자가 원하는 속도로 볼 수 있도록 되어 있으므로 모든 시나리오에 적합하지 않습니다. 다음 상황에서 다른 채널을 고려하십시오.

* 사용자가 카드를 볼 수 있는 시간에 앱 또는 웹 사이트를 열지 않을 수 있으므로 메시지는 시간에 민감한 경고입니다
* 콘텐츠 카드는 앱 또는 웹 사이트 내에만 표시되고 비활성 사용자는 이를 볼 수 없으므로 타겟 사용자는 비활성 상태입니다
* 콘텐츠는 민감하거나 영구적, 가시적 카드가 보증할 수 없는 보안 처리가 필요합니다
* 이 메시지에는 푸시 알림이나 이메일이 신속한 조치를 취할 수 있는 플래시 세일과 같은 긴급한 call to action이 필요합니다
