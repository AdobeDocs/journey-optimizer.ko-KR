# 콘텐츠 생성{#section-overview}

Adobe Journey Optimizer의 콘텐츠 생성 기능은 생성형 AI를 활용하여 이메일, SMS, 푸시 알림, 웹 페이지 등에 사용할 개인화된 텍스트와 시각 자료를 생성함으로써 콘텐츠 제작 방식을 혁신합니다. 전체 캠페인을 생성하든 특정 자산을 개선하든, 이 기능을 사용하면 시간을 절약하면서 브랜드 가이드라인에 맞게 콘텐츠를 원활하게 조정할 수 있습니다. 콘텐츠 생성 기능에 액세스하는 방법, 사용 제한 사항을 이해하고 다양한 채널에서 기능을 활용하는 방법을 살펴봅니다. 각 하위 주제에서는 눈길을 끄는 이메일 작성부터 콘텐츠 변형 실험까지 다양한 주제에 대한 실질적인 지침을 제공하여 대상자에게 공감을 불러일으키는 영향력 있고 브랜드에 맞는 캠페인을 자신 있게 만들도록 지원합니다.
